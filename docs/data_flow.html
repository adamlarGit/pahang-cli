Populate TOTAL PE Workflow src/populate_total_pe_workflow.py
Scans testsheet packages across input storage, parses substation test data, and upserts PE metadata into TOTAL PE.xlsx (Worksheet: DataCycle1). Serves as the primary metadata index for Pahang CLI.
Primary Entry Point
PopulateTotalPeWorkflow.execute()
Accepts ProjectEnvironment and PopulateTotalPeRequest
Data Storage Destination
TOTAL PE.xlsx
Worksheet: DataCycle1 | Cols: PE NO, FL NUMBER, SUBSTATION NAME, DATE, TYPE, WO, SCOPE
Execution Modes
AUTO SPECIFIC_FOLDERS
AUTO mode deduplicates against existing records; SPECIFIC_FOLDERS filters by package targets.

Input Request & Package Discovery

Receives environment configuration and request parameters. Uses SubstationTestsheetRepository to scan the testsheet directory and discover package folders.

Filtering & Existing Record Indexing
Lines 47–86

Applies requested filter mode. In AUTO mode, reads TOTAL PE.xlsx to index existing (PE/Substation, Date) pairs and filters out packages already processed.

📥 Input Data

⚙️ Key Normalization & Matching
  • Normalizes date format via normalize_date_str() (e.g. 01/05/2026 → 01-05-2026)
  • Generates key variants: (str(pe), date), (f"{pe:03d}", date), (SUB_NAME, date)
📤 Output Filter
  • Filtered list of pending/new packages to process

Workbook Provisioning & Header Initialization
Lines 93–105

Ensures target directory exists. Creates a new TOTAL PE.xlsx with standard headers if absent, or opens existing file and accesses sheet DataCycle1.

📥 Storage Path
  • environment.storage.get_total_pe_path()
⚙️ Workbook Setup
  • If missing: creates DataCycle1 sheet
  • Appends header: ["PE NO", "FL NUMBER", "SUBSTATION NAME", "DATE", "TYPE", "WO", "SCOPE"]
📤 Prepared Worksheet
  • Active openpyxl.Worksheet object ready for writing
4
Data Extraction & Upsert Logic
Lines 109–173

Indexes existing row numbers by key tuple. For each package, extracts test sheet fields (PE NO, FL Number, Substation Name, Date, Type Code, WO Number) and either updates existing row or appends new row.

📥 Extracted Fields
  • pe_number, fl_number, substation_name
  • date_str, type_code, wo_number
⚙️ Multi-Key Lookup Strategy
  • Lookup priority: Exact PE → Norm Date PE → Padded 3-digit PE → Substation Name
  • If match: updates existing row cells
  • If no match: appends row [pe_no, fl_num, sub_name, dt_str, type_c, wo, ""]
📤 Result Counters
  • new_count (incremented on row append)
  • updated_count (incremented on cell update)
5
Persistence & Result Return
Lines 174–183

💾 Disk Save
  • wb.save(total_pe_path)
  • Closes workbook stream
📤 Return Structure
  • PopulateTotalPeResult(new_rows_added=new_count)
Raw Material Workflow src/raw_material_workflow.py
Enforces strict TOTAL PE alignment and folder prerequisites, provisions standard directory structures for raw materials, parses photo range bounds from test sheets, and automatically sorts raw photos into technology folders (IR, DG, US+TEV).
Primary Entry Point
RawMaterialWorkflow.execute()
Accepts ProjectEnvironment and RawMaterialRequest
Strict Pre-Checks
TOTAL PE Check UNSORTED Gate
Fails fast if TOTAL PE missing/empty or package missing UNSORTED RAW DATA folder.
Folder Structure Provisioned
RAW DATA/{IR,DG,US+TEV}
Hierarchy: RAW_MATERIAL/Station/Month/Date/PE/RAW DATA/

📌 Step-by-Step Data Flow Analysis

1
TOTAL PE.xlsx Pre-Check & Validation
Lines 56–76

Validates that TOTAL PE.xlsx exists and contains records in DataCycle1 sheet. Prevents raw material processing if TOTAL PE workflow hasn't been executed.

📥 File Dependency
  • environment.storage.get_total_pe_path()
⚙️ Pre-Check Logic
  • Checks file existence
  • Loads workbook in read-only mode, checks max_row >= 2
🚨 Exception Trigger
  • Raises RuntimeError with explicit user instructions if file/sheet missing or empty
2
Input Package & UNSORTED RAW DATA Verification
Lines 78–102

Discovers target packages and verifies that every single discovered package contains an UNSORTED RAW DATA folder with raw photo files provided by field engineers.

📥 Target Directory
  • request.target_dir or fallback get_testsheet_dir()
⚙️ Verification Gate
  • Checks pkg.unsorted_raw_data_dir.exists() for each package
🚨 Error Handling
  • Raises RuntimeError if any package lacks UNSORTED RAW DATA/
3
Strict TOTAL PE Alignment Pre-Check
Lines 104–146

Loads TOTAL PE.xlsx records and ensures ALL discovered packages have a matching record in TOTAL PE before proceeding.

📥 Matching Keys
  • Discovered packages metadata vs TOTAL PE.xlsx entries
⚙️ Match Rules
  • Matches PE number, padded PE (005), normalized date, or Substation Name
🚨 Alignment Gate
  • Raises RuntimeError listing unmatched packages if alignment fails
4
Directory Provisioning & Path Construction
Lines 155–171

Constructs standardized nested directory hierarchy under raw material root folder for each substation package.

📥 Root Directory
  • environment.storage.get_raw_material_dir()
⚙️ Path Hierarchy Built
  • <raw_material_root>/<station>/<month>/<date_str>/<00PE_NUM>/RAW DATA/
📤 Subfolders Created
  • RAW DATA/IR/
  • RAW DATA/DG/
  • RAW DATA/US+TEV/
5
Testsheet Photo Range Extraction & Photo Sorting
Lines 172–245, 246–311

Extracts photo range numbers (e.g. IR FLIR range, DG IMG range) via TestsheetExtractor. Scans unsorted raw photos, extracts numbers, checks range bounds, and copies matching photos to target directories.

📥 Data Extracted & Files Scanned
  • photo_ranges.ir & photo_ranges.dg from test sheet
  • Files matching .jpg, .jpeg, .png in unsorted folder
⚙️ Sorting Algorithm (_sort_photos_for_tech)
  • Matches filename prefix (FLIR for IR, IMG_ for DG)
  • Extracts sequence integer via regex _extract_photo_number()
  • Validates min_val <= num <= max_val
  • Copies file using shutil.copy2()
  • Tracks missing photo numbers in range
📤 Returns & Diagnostics
  • Copies sorted photos into IR/ and DG/
  • Returns RawMaterialResult with summary & missing photo warnings
