Step 2: CBM Defect Family Planning & Partitioning

src/quick_report/cbm_defect_planner.py

Family Spec Matching

Matches defect records against QUICK_REPORT_FAMILY_SPECS. Groups defects by equipment, anchors the overview defect, and groups detail sub-defects by role.

class CbmDefectPlanner: def plan(self, defects: list[CbmDefectRecord]) -> tuple[CbmDefectFamilyPlan, ...]: plans = [] for spec in QUICK_REPORT_FAMILY_SPECS: matched = [d for d in defects if _matches(d, spec)] if not matched: continue # Group by equipment and assign overview / detail roles ... return tuple(plans)
# CbmDefectFamilyPlan Structure @dataclass(frozen=True) class CbmDefectFamilyPlan: spec: QuickReportFamilySpec overview_defects: tuple[CbmDefectRecord, ...] detail_groups: dict[str, tuple[CbmDefectRecord, ...]] item_keys: tuple[str, ...]
