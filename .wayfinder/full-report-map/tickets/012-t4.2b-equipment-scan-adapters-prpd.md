# 012: T4.2b Implement Equipment Scan Adapters & PRPD Integration

## Parent

[Full Report Generation Workflow Map](../map.md)

## Branch Strategy

Implemented directly on the single unified Full Report feature branch (no per-ticket branches).

## What to build

Concrete equipment scan adapters (Switchgear, Transformer 7-point, Feeder Pillar, Battery Bank) that construct template contexts, resolve IR and paired visual photos via `RawPhotoResolver`, generate PRPD waveform graphs via `prpd.py`, and handle defective overview page substitution per D47.

## Reuse Pointers

- `src/quick_report/prpd.py`: Re-use `generate_prpd_graphs_for_swg_panel()`, `generate_prpd_graphs_for_transformer()`, `discover_ultratev_survey_dir()`, and `build_prpd_inline_images()` for PRPD acoustic/TEV waveform plots.
- `src/quick_report/cbm_render.py`: Re-use `format_heater_amp()`, `format_busbar_position()`, and `generate_cbm_analysis_and_recommendation()`.
- `src/core/normalizers.py`: Re-use `format_testsheet_time()`, `format_date_cbm()`, and `format_heater_amp()`.
- `src/full_report/photo_resolver.py`: Re-use `RawPhotoResolver` directly for FLIR IR & visual photo pair discovery.
- `src/full_report/models.py`: Re-use `resolve_overview_compartments()`, `resolve_switchgear_compartments()`, `resolve_panel_page_count()`, and domain scan spec builders.

## Allowed Scaffolding

- Adapter classes in `src/full_report/scan_adapters.py`: `SwitchgearScanAdapter`, `TransformerScanAdapter`, `LVDBScanAdapter`, `BatteryBankScanAdapter`.
- Dataclasses: `ScanPageContext`, `ScanRenderItem`, `ScanAdapterResult`.
- Graceful missing-photo and missing-PRPD fallback wrappers returning empty strings or transparent placeholders.
- Unit test doubles and mocks for disk image discovery in `tests/test_full_report_scan_adapters.py`.

## Acceptance criteria

- [ ] Switchgear adapter renders panel scanning pages per manufacturer compartment matrix (D26, D29).
- [ ] Transformer adapter renders unconditional 7-point scanning pages per ADR 0004 and D31.
- [ ] Feeder Pillar and Battery Bank adapters render overview pages with operating parameters.
- [ ] Integrates `prpd.py` scatter plots, falling back cleanly to `""` if survey data is missing (D08).
- [ ] Implements D47 overview page substitution when equipment group has active defects.
- [ ] Unit tests verifying context generation across all equipment families.
