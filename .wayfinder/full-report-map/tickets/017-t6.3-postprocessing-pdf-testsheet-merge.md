# 017: T6.3 Post-Processing PDF Conversion & Testsheet Append

## Parent

[Full Report Generation Workflow Map](../map.md)

## GitHub Issue

[#36](https://github.com/adamlarGit/pahang-cli/issues/36)

## Branch Strategy

Implemented directly on the single unified Full Report feature branch (no per-ticket branches).

## What to build

`FullReportPostProcessingWorkflow` in `src/workflows/full_report_postprocessing.py` converting finalized Full Report `.docx` to `.pdf` via Word COM virtual printer and merging with pre-existing testsheet PDF from `processed_testsheet/pdf/` using `PyPDF2`.

## Reuse Pointers

- `src/docx_to_pdf.py`: Re-use `ComDocumentConverter`, `FakeDocumentConverter`, and `configure_uniform_printer()` for uniform A4 Word-to-PDF virtual printer export per D45.
- `src/combine_pdfs_with_separator.py`: Re-use PDF merge routines and `PyPDF2` page concatenation patterns.
- `src/core/normalizers.py`: Re-use `format_month_folder()`.

## Allowed Scaffolding

- Deep workflow class `FullReportPostProcessingWorkflow` in `src/workflows/full_report_postprocessing.py`.
- Dataclasses: `FullReportPostProcessingTelemetry`, `FullReportPostProcessingResult`.
- Pre-flight validator function enforcing presence of `processed_testsheet/pdf/<stem>.pdf` before conversion per D43.
- Unit test suite `tests/test_full_report_postprocessing.py` validating fail-fast on missing testsheet PDF, converter delegation, and merged PDF creation with `FakeDocumentConverter`.

## Acceptance criteria

- [ ] Fails fast with clear diagnostic if testsheet PDF is missing in `processed_testsheet/pdf/` per D43.
- [ ] Converts `.docx` to `.pdf` via `ComDocumentConverter` and `configure_uniform_printer` per D45.
- [ ] Merges converted PDF and testsheet PDF into final client PDF deliverable using `PyPDF2`.
- [ ] Supports swappable converter seam (`FakeDocumentConverter`) for headless testing.
- [ ] Unit tests covering missing testsheet failure, conversion, and merge steps.
