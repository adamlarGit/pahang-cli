# 009: T3.2 Implement ExecutiveSummaryCensusBuilder with Group Vertical Merge

## Parent

[Full Report Generation Workflow Map](../map.md)

## GitHub Issue

[#28](https://github.com/adamlarGit/pahang-cli/issues/28)

## Branch Strategy

Implemented directly on the single unified Full Report feature branch (no per-ticket branches).

## What to build

`ExecutiveSummaryCensusBuilder` module that traverses `SubstationEquipmentPackage`, provisions 7-point TX rows per ADR 0004, cross-references CBM defects, applies post-render Column 0 `<w:vMerge>` group numbering (`1.`, `2.`, `3.`), and applies Green `00B050` / Red `EE0000` severity shading.

## Reuse Pointers

- `src/quick_report/cbm_render.py`: Re-use `set_cell_shading()`, `clear_cell_text()`, and `_build_jinja_env()` for dynamic XML cell background coloring and text suppression.
- `src/quick_report/cbm_summary.py`: Re-use `format_temperature_reading()`, `format_db_reading()`, and `format_summary_equipment()` per D23.
- `src/core/normalizers.py`: Re-use `format_temperature_float()`, `format_db_int()`, and `normalize_us_characteristic()`.
- `src/full_report/models.py`: Re-use `has_hv_cable_split()`, `SwitchgearCategory`, `is_tx_feeder()`, and domain scan spec builders.
- `src/testsheet/models.py`: Re-use `SubstationEquipmentPackage`, `SwitchgearSpec`, `TransformerSpec`, `LVDBSpec`, and `BatteryBankSpec`.

## Allowed Scaffolding

- Dataclasses in `src/full_report/census.py`: `CensusRowItem`, `ExecutiveSummaryCensusContext`, and `ExecutiveSummaryCensusResult`.
- Deep module class `ExecutiveSummaryCensusBuilder` in `src/full_report/census.py`.
- DOM helper functions in `src/full_report/census.py` manipulating OpenXML `<w:vMerge>` elements for Column 0 grouping per D21.
- Unit test factories and mock equipment packages in `tests/test_full_report_census_builder.py`.

## Acceptance criteria

- [ ] Assembles census row items from physical equipment inventory.
- [ ] Provisions unconditional 7-point TX rows per ADR 0004 and D27.
- [ ] Emits single FP overview row when healthy, appending active defect feeder rows per D22.
- [ ] Cross-references Quick Report `CbmDefectRecord`s to set measurement readings and defect severity.
- [ ] Performs post-render OpenXML DOM pass setting `<w:vMerge>` on Column 0 with integer group numbering per D21.
- [ ] Dynamically shades Severity cells Green `00B050` (healthy) or Red `EE0000` (defective) per D24.
- [ ] Comprehensive unit tests verifying row structure across benchmark substations.
