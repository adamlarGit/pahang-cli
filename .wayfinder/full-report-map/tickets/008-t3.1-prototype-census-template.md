- `templates/QUICK REPORT/CBM DEFECT IR+US+TEV SUMMARY.docx`: Reference for table layout, column widths, font typography, header styling, and cell borders.
- `src/quick_report/cbm_summary.py`: Jinja key naming conventions (`no`, `equipment`, `defect_area`, `ir_abs`, `us_dB`, `tev_dB`, `severity`) aligned with D25.
- `src/core/normalizers.py`: Formatting conventions (`format_temperature_float`, `format_db_int`) for sample preview data.
